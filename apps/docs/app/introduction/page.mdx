# Introduction

SYMM Frontier is a modern application built with cutting-edge technologies.

## What is SYMM Frontier?

SYMM Frontier provides a robust foundation for building scalable applications.

## Key Concepts

### Architecture

The project follows a monorepo structure with:

- **Apps**: Individual applications
- **Packages**: Shared libraries and configurations

### Technology Stack

- **Next.js**: React framework
- **TypeScript**: Type-safe development
- **Turborepo**: Monorepo management
- **pnpm**: Fast package manager
