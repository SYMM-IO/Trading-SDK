# Guides

End-to-end recipes that cut across multiple SDK slices. Each guide picks one UI surface (a chart, a panel, a flow) and walks the full wiring — which hooks to call, which data to derive from which endpoint, which framework primitives to reach for.

Guides are **consumer-facing**. Reference docs under [Core](../core), [React](../react), and the other library sections describe individual APIs; guides show how to combine them.

## Available guides

- [Build a Perps DEX](./build-a-dex) — end-to-end recipe for shipping a full trading UI. Start on the [overview](./build-a-dex) to pick your path: [with React](./build-a-dex/react) (recommended, on `@symmio/trading-react`) or [with Core](./build-a-dex/core) (framework-agnostic, on `@symmio/trading-core`, for Node.js and non-React stacks). Both walk wallet, subaccounts, collateral, delegation, open / close, and TP/SL.
- [Register an Affiliate](./affiliate-registration) — register your frontend as a SYMMIO affiliate so trading fees route to you. Predict your deterministic address, submit the on-chain request, get approved, then wire the address into your config. Use the hosted page or drive it from your own UI with the SDK.
- [Charts](./charts) — render a price chart for any market. [Majors](./charts/majors) stream real OHLCV from a reference exchange through the SDK's `CandleSource`; [lowcaps](./charts/lowcap) have no such listing and chart from their liquidity pool instead, via a DexScreener embed or your own OHLC feed.
- [Orderbook](./orderbook) — render live market depth. A pluggable `OrderbookSource` keeps a book continuously synchronized against the venue's own sequence rules, so a ladder is never quietly wrong, and the grouping, spread and impact helpers work on any source's book.

## When to reach for a guide vs a reference

- **Reference** — "what does `useEnigmaPriceServiceMetadata` return?" → [Core / Price Service](../core/price-service) or [React / Price Service hooks](../react/price-service).
- **Guide** — "how do I show a price chart for a market?" → this section.

New guides are added as new UI patterns crystallize. If a recipe exists in a reference frontend and belongs in the SDK's documented surface, propose it as a guide.
