# getForceClosePriceSig

Fetch a fresh Muon `priceRange` attestation for a time window, assembled into the contract-ready `HighLowPriceSig` that `forceClosePosition` / `settleAndForceClosePosition` verify — the proof that the market traded through the position's close price during the window. For the raw, un-assembled attestation (all returned fields), use [`getMuonPriceRange`](/core/muon/price-range) instead. The oracle URLs and the SYMMIO diamond address are resolved from `config`; gateways are tried in order until one succeeds.

The attestation is timestamped and short-lived — fetch it immediately before submitting, not ahead of time.

```ts
import { getForceClosePriceSig } from "@symmio/trading-core";

const sig = await getForceClosePriceSig(config, {
  partyA,
  partyB: solverAddress,
  symbolId: 1n,
  t0: windowStart,
  t1: windowEnd,
});
```

## Parameters

<Properties>
  <Property name="t0" type="bigint" required>

  </Property>
  <Property name="t1" type="bigint" required>
    Window end timestamp (unix seconds).
  </Property>
  <Property name="partyA" type="Address" required>
    PartyA of the position being force-closed.
  </Property>
  <Property name="partyB" type="Address" required>

  </Property>
  <Property name="symbolId" type="bigint" required>
    Market symbol id of the position.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
</Properties>

## Returns

A contract-ready struct mirroring the on-chain `HighLowPriceSig` tuple field-for-field, so it encodes directly as the contract argument.

Three of the wire names differ from the struct's: Muon returns `mean` for `averagePrice`, `price` for `currentPrice`, and `uPnlB` / `uPnlA` for `upnlPartyB` / `upnlPartyA`. Note also that **`upnlPartyB` is declared before `upnlPartyA`** — swapping them type-checks green and silently mis-encodes the call.

<Returns type="HighLowPriceSig">
  <Property name="reqId" type="Hex">
    Muon request id (opaque bytes).
  </Property>
  <Property name="timestamp" type="bigint">

  </Property>
  <Property name="symbolId" type="bigint">
    Symbol id the price range is for.
  </Property>
  <Property name="highest" type="bigint">
    Highest price observed in the window, 18-decimal fixed point.
  </Property>
  <Property name="lowest" type="bigint">
    Lowest price observed in the window, 18-decimal fixed point.
  </Property>
  <Property name="averagePrice" type="bigint">
    Mean price over the window, 18-decimal fixed point.
  </Property>
  <Property name="startTime" type="bigint">
    Window start timestamp (seconds).
  </Property>
  <Property name="endTime" type="bigint">
    Window end timestamp (seconds).
  </Property>
  <Property name="upnlPartyB" type="bigint">
    PartyB's signed unrealized PnL, `int256`. Declared **before** `upnlPartyA`.
  </Property>
  <Property name="upnlPartyA" type="bigint">
    PartyA's signed unrealized PnL, `int256`.
  </Property>
  <Property name="currentPrice" type="bigint">
    Current price at attestation time, 18-decimal fixed point.
  </Property>
  <Property name="gatewaySignature" type="Hex">

  </Property>
  <Property name="sigs" type="SchnorrSign">
    The Schnorr TSS signature pieces (`signature`, `owner`, `nonce`).
  </Property>
</Returns>

## Query options

```ts
import { getForceClosePriceSigQueryOptions } from "@symmio/trading-core";
import { useQuery } from "@tanstack/react-query";

useQuery(getForceClosePriceSigQueryOptions(config, { partyA, partyB, symbolId, t0, t1 }));
```

`GetForceClosePriceSigOptions` requires every action input; the factory does not accept missing inputs or validate them inside `queryFn`. The `getForceClosePriceSigQueryKey` builder still accepts partial inputs for cache matching and invalidation. Because the signature is short-lived, prefer fetching on demand right before the write over serving a cached one.
