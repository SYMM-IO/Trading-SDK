# getEnigmaPriceServicePreset

Select the production or staging Enigma lowcap price service without copying endpoint URLs into your app. This pure config helper returns a fresh `SymmioPriceServiceConfig` on every call and works in browsers and Node.js.

It changes only price-service configuration. Keep your deployment's contract addresses, solver, affiliate, and other services configured separately. Production and staging can share a chain ID, so select the environment explicitly.

## Signature

```ts
import { getEnigmaPriceServicePreset } from "@symmio/trading-core";
import type { GetEnigmaPriceServicePresetParameters, SymmioPriceServiceConfig } from "@symmio/trading-core";

// Parameters: { environment: "production" | "staging" }
// Returns: SymmioPriceServiceConfig
const priceService = getEnigmaPriceServicePreset({ environment: "staging" });
```

| Input         | Meaning                                                            |
| ------------- | ------------------------------------------------------------------ |
| `environment` | Required: `production` or `staging`. No wallet or chain inference. |

The result contains `type: "enigma"`, `url` for REST, and `wsUrl` for the broadcast stream. Mutating the returned object cannot change future presets or the built-in registry.

## Configure a deployment

```ts
import { createConfig, getEnigmaPriceServicePreset } from "@symmio/trading-core";
import { createPublicClient, http, zeroAddress } from "viem";
import { arbitrum } from "viem/chains";

const priceService = getEnigmaPriceServicePreset({ environment: "staging" });
const client = createPublicClient({ chain: arbitrum, transport: http() });
const config = createConfig({
  defaultChainId: arbitrum.id,
  getClient: () => client,
  symmioConfig: {
    [arbitrum.id]: {
      addresses: { affiliatesAddress: zeroAddress }, // Read-only example.
      priceService,
      solvers: { enigma: { priceService } },
    },
  },
});
```

A solver-level `priceService` takes precedence over the chain-level block. Set both consistently when configuring a deployment; the chain block also serves the Enigma metadata and symbol-info actions. This example configures price reads only and is not a complete staging trading configuration.

Arbitrum's built-in production configuration already uses the production preset. React applications can pass the same blocks to `SymmioProvider`.

## Read prices

Use SDK `getMarkPrices(config, { chainId, solverId: "enigma", names })` for a one-time mark snapshot. Keep live displays on [`watchEnigmaPrices`](../watch-enigma-prices), which shares the connection and delivers updates without polling. Fetch at most 50 names per named request. Keep canonical market names rather than display tickers, which may not be unique.
