# partitionQuotes

Split a flat quote list into active positions and resting/pending orders. Run this before [`groupQuotes`](/core/quotes/group-quotes) — a limit order that has not filled is not part of a position and must not be folded into one.

```ts
import { partitionQuotes, groupQuotes, SubAccountIsolationType } from "@symmio/trading-core";

const { positions, pending } = partitionQuotes(quotes);
const groups = groupQuotes(positions, SubAccountIsolationType.MARKET_DIRECTION);
```

`isPendingOrder` and `isActivePosition` are exported separately for callers that need the predicate rather than the split, and [`isActiveQuoteStatus`](#isactivequotestatus) tests a bare on-chain status.

Both classify an anchored row by its on-chain [`QuoteStatus`](/core/quotes/quote-status) — `PENDING` / `LOCKED` / `CANCEL_PENDING` is a resting order, `OPENED` / `CLOSE_PENDING` / `CANCEL_CLOSE_PENDING` / `LIQUIDATED_PENDING` is a position — falling back to lifecycle + order type only for a row that has no status yet. Terminal rows match neither and are dropped.

<Callout type="warning">
  **Do not substitute `openQuantity > 0`.** That field is `quantity − closedAmount`, so a quote that never opened still
  reports its full size: splitting on it files every resting `LOCKED` limit order under positions, where the only
  action offered is a Close the protocol will reject. The state table on
  [`QuoteStatus`](/core/quotes/quote-status#what-each-state-allows) has what each row can actually do.
</Callout>

## `isActiveQuoteStatus`

Whether an on-chain [`QuoteStatus`](/core/quotes/quote-status) is an active position: `OPENED`, `CLOSE_PENDING`, `CANCEL_CLOSE_PENDING` or `LIQUIDATED_PENDING` — the same set `isActivePosition` uses for an anchored row. These are the only statuses whose pending funding is meaningful.

Unlike `isActivePosition`, it takes a **known** status and has no lifecycle fallback, so it never counts an optimistic or just-anchored row (`quoteStatus` still `undefined`) as a position. Use it to pick the quotes to pass to [`getQuotePendingFunding`](/core/symmio-contract/get-quote-pending-funding), whose view does not check status and returns a meaningless amount for a quote that was locked but never opened.

```ts
import { getQuotePendingFunding, isActiveQuoteStatus } from "@symmio/trading-core";

const quoteIds = quotes.flatMap((quote) =>
  quote.quoteId !== undefined && quote.quoteStatus !== undefined && isActiveQuoteStatus(quote.quoteStatus)
    ? [quote.quoteId]
    : [],
);
const rows = await getQuotePendingFunding(config, { quoteIds });
```
