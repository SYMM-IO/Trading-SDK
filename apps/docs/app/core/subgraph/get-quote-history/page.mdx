# getQuoteHistory

Terminal (close / liquidation) events for a set of accounts' quotes. Each row is a single immutable `QuoteEvent` with its per-event `metadata` snapshot overlaid onto the (otherwise mutable) quote it belongs to — so a quote closed across several partial closes produces several distinct history rows. Each row also carries the quote's own indexed fields — fees, CVA / LF, leverage, open timestamps, the open transaction — so a history table needs no second read.

```ts
import { getQuoteHistory } from "@symmio/trading-core";

const { rows } = await getQuoteHistory(config, {
  subAccounts: [subAccount],
  first: 100,
});
```

Every account, deployment, and market filter is optional and applied only when passed — see [Filters and paging](/core/subgraph#filters-and-paging). Omit `subAccounts` to read every account's history, for example a deployment-wide feed scoped by `source` and `marketIds`.

## Parameters

<Properties>
  <Property name="subAccounts" type="readonly Address[]" optional>
    The accounts whose history to read — a SubAccount and/or its Virtual Accounts. The query filters on the quote's
    `subAccount` (or `partyA`, see `isolationType`), so pass every account that may own the relevant quotes. Omit to
    read every account's history; an empty array reads nothing.
  </Property>
  <Property name="isolationType" type="SubAccountIsolationType" optional>
    Picks the account filter field. `CUSTOM` (cross-margin) filters on the quote's `partyA`, because cross-margin quotes
    carry no `subAccount` on the subgraph; `MARKET` / `MARKET_DIRECTION` (and the default) filter on the quote's
    `subAccount`. Every account in one call must share it.
  </Property>
  <Property name="source" type="Address" optional>
    The deployment's diamond address (`quote_.source`). Omit to read every deployment the subgraph indexes.
  </Property>
  <Property name="marketIds" type="readonly number[]" optional>
    Market ids to read (`quote_.symbolId_in`). Omit for every market; an empty array reads nothing.
  </Property>
  <Property name="closeType" type="QuoteCloseType" default="All">
    Close-type filter: `All`, `Closed` (`FILL_CLOSE`), `ForceClosed`, `EmergencyClosed`, `AdlClosed`, or `Liquidated`.
  </Property>
  <Property name="first" type="number" default="50">
    Page size.
  </Property>
  <Property name="skip" type="number" default="0">
    Page offset.
  </Property>
  <Property name="startTime" type="number" default="0">
    Lower bound on the event timestamp (unix seconds).
  </Property>
  <Property name="endTime" type="number" default="2_000_000_000">
    Upper bound on the event timestamp (unix seconds).
  </Property>
  <Property name="orderDirection" type='"asc" | "desc"' default="desc">
    Sort direction on the event timestamp.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
</Properties>

## Returns

<Returns type="GetQuoteHistoryReturnType">
  <Property name="rows" type="QuoteHistoryRow[]">
    History rows in event-timestamp order. Each is a terminal `QuoteEvent` (its `closeEventType` is one of the
    `QuoteCloseEventType` values) with the event's immutable `metadata` snapshot overlaid onto the quote's fields, so
    partial closes read as separate rows with the amounts they closed. See [Unified quotes](/core/quotes) for the
    reconciled quote model these rows decorate.
  </Property>
</Returns>

## Row fields

All amounts and prices are raw `bigint` in 18-decimal fixed point, the same scale as the on-chain [`Quote`](/core/symmio-contract/get-quote) read. Enum fields are decoded.

### The event and its snapshot

These fields describe the close itself. Where the event's `metadata` snapshot carries a value (`amount`, `closePrice`, `openedPrice`), it wins over the quote's mutable value.

  <Property name="avgClosedPrice" type="bigint">

## Solver fees

Each row carries the solver fees the event charged, decoded from the `metadata` snapshot's `solverFees` list. All three are 18-decimal wei of collateral.

<Properties>
  <Property name="solverFee" type="bigint | null">
    The rate-based fee (`SOLVER_FEE` on the wire) — `notional × rate`, so it scales with the size this event settled.
    `null` when the event carried no such entry.
  </Property>
  <Property name="staticSolverFee" type="bigint | null">
    The flat fee (`STATIC_SOLVER_FEE` on the wire) — a fixed per-event charge, independent of the settled size. `null`
    when the event carried no such entry.
  </Property>
  <Property name="totalSolverFee" type="bigint | null">
    Sum of **every** entry in the list, including tags a future contracts release may add that have no named field here,
    so the total never under-reports. `null` when the event recorded no `solverFees` at all.
  </Property>
</Properties>

**Availability.** Only `FILL_CLOSE` events record solver fees. Liquidation and ADL rows read `null` on all three fields, as do deployments indexed before the fee was recorded (Base analytics today). Treat `null` as "not recorded" and render it as such — a `0` would claim the solver charged nothing.

The untruncated list stays on `rawMetadata`, so a tag the SDK does not name individually is still reachable:

```ts
const { solverFees } = JSON.parse(row.rawMetadata ?? "{}");
// [["SOLVER_FEE", "659102399999999"], ["STATIC_SOLVER_FEE", "100000000000000000"]]
```

## Open-position metadata

`openPositionMetadata` holds the raw `metadata` string of each `OPEN_POSITION` event on the quote, up to 1000 (the subgraph's page ceiling). The SDK does not decode it and does not judge whether the list is complete: a quote with exactly 1000 entries may have more. Parse what you need — for example the solver fees paid at open:

```ts
const opens = row.openPositionMetadata.map((raw) => (raw ? JSON.parse(raw) : null));
```

## Query options

```ts
import { getQuoteHistoryQueryOptions } from "@symmio/trading-core";
import { useQuery } from "@tanstack/react-query";

useQuery(getQuoteHistoryQueryOptions(config, { subAccounts: [subAccount] }));
```

The query is disabled while `subAccounts` or `marketIds` is an empty array.
