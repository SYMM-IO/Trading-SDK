# SYMMIO Contract

Reads and writes against the on-chain SYMMIO diamond contract — quotes, collateral, allocation, withdraw, and the on-chain market list. This slice targets the `Symmio` contract directly via viem clients.

Solver-side catalog / limit reads (`getMarkets`, `getLockedParams`, `getNotionalCapBySymbolId`, `getOpenInterestBySymbolId`) hit the solver REST API and live under [Solvers](/core/solvers) — they are **not** contract reads even when the numbers ultimately reflect on-chain state.

Each method has its own page with the full signature, parameters, return shape, examples, and query options.

## Allocate / deallocate

`allocate` and `deallocate` move collateral between an account's available and allocated balances. They are the same on-chain writes documented under AccountLayer — see [`allocate`](/core/account-layer/allocate) and [`deallocate`](/core/account-layer/deallocate).
