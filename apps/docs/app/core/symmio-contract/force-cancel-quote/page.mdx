# forceCancelQuote

Force-cancel a stalled quote. Only valid once the quote is `CANCEL_PENDING` — you called [`requestToCancelQuote`](/core/symmio-contract/request-to-cancel-quote) on a `LOCKED` order and partyB never acted — **and** the force-cancel cooldown has elapsed. Like the cancel request, it is routed through `AccountLayer._call(account, …)`, so the connected wallet must be the subaccount's `owner`.

Eligibility: `now ≥ quote.statusModifyTimestamp + getCoolDownsOfMA()[1]`. A `PENDING` (unlocked) quote cancels instantly via `requestToCancelQuote` and never reaches this path.

```ts
import { forceCancelQuote } from "@symmio/trading-core";

const hash = await forceCancelQuote(config, { account: "0xsub…", quoteId: 42n });
```

## Parameters

<Properties>
  <Property name="account" type="Address" required>
    The subaccount (partyA) that owns the quote. Routed through the AccountLayer `_call` proxy so the diamond sees this
    subaccount as the caller.
  </Property>
  <Property name="quoteId" type="bigint" required>
    The on-chain id of the `CANCEL_PENDING` quote to force-cancel.
  </Property>
  <Property name="from" type="Address" optional>
    Override the wallet address that signs. Defaults to the account's owner.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
  <Property name="gasless" type="boolean | GaslessWriteOptions" optional>
    Relay this write through the [gasless execution mode](/core/gasless/relayable-writes) instead of the wallet. A
    boolean for the common case, or a per-call `GaslessWriteOptions` bag; omitted, the chain's `execution.mode` decides.
  </Property>
</Properties>

## Returns

<Returns type="Hash">The transaction hash.</Returns>

## Gasless execution

<Callout type="info">
  `forceCancelQuote` is relayable through the [gasless execution mode](/core/gasless/relayable-writes) — pass `gasless:
  true` (or set the chain's `execution.mode` to `"gasless"`) and the SDK signs the same calldata as an InstantLayer
  operation, relays it, and returns the relayer’s broadcast hash; the return type and receipt behavior are unchanged.
</Callout>
