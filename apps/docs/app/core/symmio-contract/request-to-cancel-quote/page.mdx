# requestToCancelQuote

Cancel a pending quote — how a partyA cancels a resting **LIMIT order**. The core `requestToCancelQuote(quoteId)` must be attributed to the subaccount, so it is encoded and routed through `AccountLayer._call(account, …)`; the connected wallet must be the subaccount's `owner` (no session key).

A `PENDING` (unlocked) quote cancels instantly. A `LOCKED` quote (a partyB is committed) enters `CANCEL_PENDING` and waits out the force-cancel cooldown before it can be finished with [`forceCancelQuote`](/core/symmio-contract/force-cancel-quote).

```ts
import { requestToCancelQuote } from "@symmio/trading-core";

const hash = await requestToCancelQuote(config, { account: "0xsub…", quoteId: 42n });
```

## Parameters

<Properties>
  <Property name="account" type="Address" required>
    The subaccount (partyA) that owns the quote. The call is routed through the AccountLayer `_call` proxy so the
    diamond sees this subaccount as the caller.
  </Property>
  <Property name="quoteId" type="bigint" required>
    The on-chain id of the quote to cancel.
  </Property>
  <Property name="from" type="Address" optional>
    Override the wallet address that signs. Defaults to the account's owner.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
  <Property name="gasless" type="boolean | GaslessWriteOptions" optional>
    Relay this write through the [gasless execution mode](/core/gasless/relayable-writes) instead of the wallet. A
    boolean for the common case, or a per-call `GaslessWriteOptions` bag; omitted, the chain's `execution.mode` decides.
  </Property>
</Properties>

## Returns

<Returns type="Hash">The transaction hash.</Returns>

## Gasless execution

<Callout type="info">
  `requestToCancelQuote` is relayable through the [gasless execution mode](/core/gasless/relayable-writes) — pass
  `gasless: true` (or set the chain's `execution.mode` to `"gasless"`) and the SDK signs the same calldata as an
  InstantLayer operation, relays it, and returns the relayer’s broadcast hash; the return type and receipt behavior are
  unchanged.
</Callout>
