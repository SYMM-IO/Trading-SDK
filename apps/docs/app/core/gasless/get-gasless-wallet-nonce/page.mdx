# getGaslessWalletNonce

Read the GaslessLayer's **wallet-operation** replay nonce for an account — the counter behind [`gaslessWalletExecute`](/core/gasless/gasless-wallet-execute) signatures.

```ts
import { getGaslessWalletNonce } from "@symmio/trading-core";

const current = await getGaslessWalletNonce(config, { account: owner });
// a wallet operation signs with current + 1n
```

This is a **separate counter** from the InstantLayer's operation nonces ([`getInstantLayerNonce`](/core/instant-layer/get-instant-layer-nonce)) — the two are not interchangeable. Like every gasless nonce it is sequential: sign with `nonce + 1`, read immediately before signing, and never build two operations from one read. `gaslessWalletExecute` does all of this internally; reach for the raw read only when assembling wallet operations yourself.

## Parameters

<Properties>
  <Property name="account" type="Address" required>
    The account whose wallet-operation nonce to read (the owner wallet).
  </Property>
  <Property name="chainId" type="number" optional>
    Target chain id. Defaults to the config's `defaultChainId`.
  </Property>
</Properties>

## Returns

<Returns type="Promise<bigint>">The current on-chain wallet-operation nonce. Sign with `nonce + 1n`.</Returns>

## Throws

- `SymmError("config", "GASLESS_NOT_CONFIGURED")` / `("config", "GASLESS_UNSUPPORTED_CONTRACTS_VERSION")`.
- Viem read errors.
