# Core

`@symmio/trading-core` is the framework-agnostic SYMMIO SDK. Contract calls, REST clients, GraphQL subgraph reads, WebSocket streams, calculations, and typed errors — no framework assumptions.

Framework layers sit on top of `core` and inject the viem-client resolvers it needs. Today that layer is `@symmio/trading-react`. Because `core` stays framework-agnostic, other layers (Vue, Solid, or anything else) can be added later without rewriting it.

## Install

```sh
pnpm add @symmio/trading-core viem
```

`viem` is the only peer dependency — bring your own copy.

## Shape

Every read is `getXyz(config, params)`; every write is `xyz(config, params)`. The **config** is always the first argument — a single immutable [`Config`](/core/concepts/config) object created once with [`createConfig`](/core/concepts/config), shared across every call.

```ts
import { createConfig, getUserSubAccounts } from "@symmio/trading-core";
import { createPublicClient, http } from "viem";
import { hyperEvm } from "viem/chains";

const publicClient = createPublicClient({ chain: hyperEvm, transport: http() });

const config = createConfig({
  symmioConfig: {
    [SymmioSupportedChainId.HYPER_EVM]: { addresses: { affiliatesAddress: "0xYourRegisteredAffiliate…" } },
  },
  getClient: () => publicClient,
});

const subs = await getUserSubAccounts(config, { user: "0xabc..." });
```

Every read also ships a matching `getXyzQueryOptions(config, options)` factory returning a fully-formed TanStack Query options bag — feed it into `useQuery` or `queryClient.fetchQuery`.

See [Config](/core/concepts/config) and [Query options](/core/concepts/query-options).

## Core Concepts

Cross-cutting mental model referenced by every slice.

- **[Config](/core/concepts/config)** — `createConfig`, injected client resolvers, chain overrides, WebSocket constructor.
- **[Query Options](/core/concepts/query-options)** — the `getXyzQueryOptions` / `xyzMutationOptions` factory pattern.
- **[Query Keys](/core/concepts/query-keys)** — key shape, `filterQueryOptions`, `predicateMatch` invalidation.
- **[WebSocket Streams](/core/concepts/websocket)** — `SocketStatus`, reconnect, connection pool.
- **[Errors](/core/concepts/errors)** — `SymmError` / `SymmApiError` catalogue, viem pass-through.

## Reference

Every domain slice, one page. Each page follows the same anatomy — purpose → import → per-action signature + params + returns + example → related.

### Contracts

- **[ABI fragments](/core/abi)** — raw viem `Abi` arrays for the escape hatch.
- **[Addresses](/core/addresses)** — per-chain contract address registry.
- **[AccountLayer](/core/account-layer)** — SubAccount / Virtual Account creation, deposits, margin management.
- **[InstantLayer](/core/instant-layer)** — delegation reads + `grantDelegation`.
- **[SYMMIO Contract](/core/symmio-contract)** — markets, quotes, collateral, allocation, withdraw against the `Symmio` contract.

### Trading

- **[Unified Quotes](/core/quotes)** — `reconcileQuotes`, `UnifiedQuote`, `applyNotificationToQuotes`, `QuoteLifecycle`.
- **[Solvers](/core/solvers)** — solver REST reads (markets, locked params). Nested:
  - [Instant Open](/core/solvers/instant-open)
  - [Instant Close](/core/solvers/instant-close)
- **[TP/SL](/core/tpsl)** — conditional-order handler surface (HTTP + WebSocket).

### Data

- **[Price Service](/core/price-service)** — Enigma mark prices, metadata, health, live stream.
- **[Orderbook](/core/orderbook)** — pluggable `OrderbookSource`, synchronized live depth, grouping, spread, impact.
- **[Pools](/core/pools)** — lowcap listing catalog: `getListingMarkets`, `resolveListingService`, `ListingMarket`, `LISTING_VALUE_DECIMALS`.
- **[Inventory](/core/inventory)** — the custody backend behind Pools, a separate vendor: `getInventoryTvl` (system-wide TVL as an 18-decimal `bigint`), `resolveInventoryService`, `INVENTORY_VALUE_DECIMALS`.
- **[Notifications](/core/notifications)** — solver notifications stream (`watchNotifications`) + REST history (`searchNotifications`).
- **[Subgraph](/core/subgraph)** — balance history, transfers, quote history, quote events, quote funding.
- **[Muon Oracle](/core/muon)** — UPNL / price / range signature helpers for on-chain writes that need Muon attestations.

### Types

- **[Shared Types](/core/shared-types)** — `ChainIdParameter`, `ConfigParameter`, `QueryParameter`, `SymmioQueryOptions`, WebSocket types, TS helpers.

## What `core` doesn't do

- React hooks. Use **[`@symmio/trading-react`](/react)**.
- Decimal-based math or display formatters. Use **[`@symmio/utils`](/utils)**.
- UI primitives. Use **[`@symmio/ui`](https://github.com/SYMM-IO)**.
