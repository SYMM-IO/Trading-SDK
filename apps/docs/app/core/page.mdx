# Core

`@theoldvarorg/core` is the framework-agnostic SDK. It wraps SYMMIO contract calls behind a small typed API built on [viem](https://viem.sh).

## Install

```sh
pnpm add @theoldvarorg/core viem
```

`viem` is a peer dependency — bring your own copy.

## Shape

Two ways to call a method, depending on how much ergonomics you want:

### Free functions

The canonical primitive. Tree-shakable, idiomatic viem.

```ts
import { getUserSubAccounts } from "@theoldvarorg/core";
import { createPublicClient, http } from "viem";
import { hyperEvm } from "viem/chains";

const publicClient = createPublicClient({ chain: hyperEvm, transport: http() });

const subs = await getUserSubAccounts(publicClient, { user: "0xabc..." });
```

### viem actions

If you'd rather hang SDK methods off a viem client, use `.extend()` with one of the action factories:

```ts
import { accountLayerReadActions } from "@theoldvarorg/core";

const reader = createPublicClient({ chain: hyperEvm, transport: http() }).extend(accountLayerReadActions);

await reader.getUserSubAccounts({ user: "0xabc..." });
```

## Slices

- **[AccountLayer](/core/account-layer)** — read and write methods on the `AccountLayer` contract (subaccounts).
- **[InstantLayer](/core/instant-layer)** — delegated signer reads and `grantDelegation`.
- **[Solvers](/core/solvers)** — solver REST reads for markets and locked params.
- **[Price Service](/core/price-service)** — Enigma price-service reads for mark prices, symbol metadata, symbol listings, and health.
- **[Errors](/core/errors)** — `SymmError` and viem error pass-through.
- **[Addresses](/core/addresses)** — per-chain contract address registry.

## What `core` doesn't do

- React hooks. Use **[`@theoldvarorg/react`](/react)**.
- Decimal-based math or display formatters. Use **[`@theoldvarorg/utils`](/utils)**.
