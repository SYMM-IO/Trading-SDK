# NotificationSearchResult

The result of [`searchNotifications`](/core/notifications/search-notifications), normalized **per solver kind**. It is a discriminated union on `kind` — narrow on it (or pass a literal `solverId` to `searchNotifications`) to reach the variant's fields.

```ts
type NotificationSearchResult = EnigmaNotificationSearchResult | RasaNotificationSearchResult;
```

`NotificationSearchResultByKind` maps each kind to its variant (`{ enigma: EnigmaNotificationSearchResult; rasa: RasaNotificationSearchResult }`); indexing it by the caller's `solverId` is how the `searchNotifications` return narrows.

## EnigmaNotificationSearchResult

A page from an **enigma** solver — the standalone notification service's stored documents.

<Properties>
  <Property name="kind" type='"enigma"'>
    Discriminant: this page came from an enigma solver.
  </Property>
  <Property name="total" type="number">
    Total documents matching the filter, ignoring pagination (enigma service only).
  </Property>
  <Property name="count" type="number">
    Number of rows returned in this page.
  </Property>
  <Property name="rows" type="NotificationDocument[]">
    The matched documents for the requested `start` / `size` window.
  </Property>
</Properties>

## RasaNotificationSearchResult

A page from a **rasa** solver — the solver's own position-state records (`POST /position-state/{start}/{size}`), which are the rasa protocol's notification history. There is **no `total`** field.

<Properties>
  <Property name="kind" type='"rasa"'>
    Discriminant: this page came from a rasa solver.
  </Property>
  <Property name="count" type="number">
    Total matching rows on the solver, for paging.
  </Property>
  <Property name="rows" type="PositionStateResponseSchema[]">
    The matched position-state rows for the requested window (`quote_id`, `counterparty_address`, `filled_amount_open` /
    `filled_amount_close`, `avg_price_open` / `avg_price_close`, `last_seen_action`, `action_status`, timing fields, …).
  </Property>
</Properties>

## NotificationDocument

A stored notification document as returned by the **enigma** search endpoint. Only the well-known top-level fields are typed; an index signature (`[key: string]: unknown`) keeps app-specific fields reachable. For trading notifications the `data` payload is the position wire frame ([`RawPositionNotification`](/core/notifications/raw-position-notification)).

<Properties>
  <Property name="id" type="string" optional />
  <Property name="app_name" type="string" optional>
    Publishing app / channel identity, e.g. `"Hyper-EVM_Solver-Low-Cap_Production"`.
  </Property>
  <Property name="address" type="string" optional>
    SubAccount address the notification belongs to.
  </Property>
  <Property name="primary_identifier" type="number" optional />
  <Property name="secondary_identifier" type="string | number | null" optional />
  <Property name="type" type="string" optional>
    `report` | `alert`.
  </Property>
  <Property name="create_time" type="number" optional />
  <Property name="modify_time" type="number" optional />
  <Property
    name="data"
    type="RawPositionNotification & Record<string, unknown>"
    typeHref="/core/notifications/raw-position-notification"
    optional
  >
    App-specific payload; the position wire frame for trading notifications.
  </Property>
</Properties>
