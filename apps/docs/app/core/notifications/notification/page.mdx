# Notification

A normalized, classified notification the SDK delivers to consumers.

camelCase, with `quoteId` resolved to the on-chain id when available (falling back to the temp id), and `type` classified from `actionStatus`. The original wire frame is preserved on `raw` for advanced use. Both [`watchNotifications`](/core/notifications/watch-notifications) and [`normalizeNotification`](/core/notifications/normalize-notification) produce this shape.
