# TpSlSigningSpec

The handler `/signing-spec` payload — the EIP-712 typed-data domain + schema a TP/SL message is signed against. Returned by [`getTpSlSigningSpec`](/core/tpsl/get-tpsl-signing-spec) (POST) and [`getTpSlDeleteSigningSpec`](/core/tpsl/get-tpsl-delete-signing-spec) (DELETE), and consumed by [`signTpSlRequest`](/core/tpsl/sign-tpsl-request). Server-published and stable per deployment, so the SDK never hardcodes the schema.
