# TpSlValidation

The outcome of [`validateTpSl`](/core/tpsl/validate-tpsl). A discriminated union on `ok`: `ok: true` means every supplied side passed; `ok: false` carries per-side error strings so the UI can render them inline. The SDK never throws — the caller decides whether to surface, block, or proceed.

```ts
type TpSlValidation =
  | { ok: true; tpError?: undefined; slError?: undefined }
  | { ok: false; tpError?: string; slError?: string };
```
