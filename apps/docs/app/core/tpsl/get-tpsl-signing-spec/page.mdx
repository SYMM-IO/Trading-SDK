# getTpSlSigningSpec

Fetch the handler's EIP-712 signing spec for the **POST** endpoint (create / edit). The spec drives the `domain`, `types`, and `primaryType` that [`setQuoteTpSl`](/core/tpsl/set-quote-tpsl) signs against, so the SDK never hardcodes the schema.

The reader shares concurrent requests and retains complete successful schemas for five minutes after the response arrives. Cache hits do not extend that lifetime. Sharing is scoped to the same SDK `Config` instance, resolved chain/config fingerprint, handler URL, `App-Name`, and POST or DELETE operation. A new config or destination uses a separate cache. Failed or incomplete responses are not retained; an expired schema is never used as a fallback after a failed refresh.

Called internally by `setQuoteTpSl`; exposed for advanced consumers that sign their own messages. Only the schema is cached. Order messages, salts, signatures, and mutation results remain fresh for every action. Returned schemas can be modified without changing the retained cache entry.

```ts
import { getTpSlSigningSpec } from "@symmio/trading-core";

const spec = await getTpSlSigningSpec(config);
// { domain, types, primaryType }
```

## Parameters

<Properties>
  <Property name="chainId" type="number" optional>
    Target chain id. Defaults to the config's `defaultChainId`.
  </Property>
</Properties>

## Returns

<Returns type="TpSlSigningSpec" typeHref="/core/tpsl/tpsl-signing-spec">
  The EIP-712 typed-data domain + schema. Pass to [`signTpSlRequest`](/core/tpsl/sign-tpsl-request).
</Returns>

## Throws

- `SymmError` when the chain has no `tpsl` config.
- `SymmApiError` when the HTTP request fails.

## Query options

```ts
import { getTpSlSigningSpecQueryOptions } from "@symmio/trading-core";
import { useQuery } from "@tanstack/react-query";

useQuery(getTpSlSigningSpecQueryOptions(config));
```

`getTpSlSigningSpecQueryOptions` takes no required inputs. Its query function uses the shared five-minute reader cache; TanStack Query freshness is controlled separately by `query.staleTime`. The existing React hook defaults to `Infinity`, which does not change the cache used directly by write actions. `getTpSlSigningSpecQueryKey` builds the matching cache key.
