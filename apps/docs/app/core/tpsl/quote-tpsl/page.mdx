# QuoteTpSl

A folded TP/SL snapshot for a single quote — both sides merged from the handler's per-conditional-order [rows](/core/tpsl/quote-tpsl-row). This is the UI-facing shape the React layer's `toQuoteTpSl` produces; `core` returns the raw rows and leaves folding to the consumer.
