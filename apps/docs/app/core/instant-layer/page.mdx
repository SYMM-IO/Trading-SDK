# InstantLayer

The `InstantLayer` contract manages delegated signer access for instant actions. SYMM Trading-SDK exposes the delegation reads as separate APIs: one reads the raw expiry timestamp from `delegations`, one reads the contract's computed active status from `isDelegationActive`, and one reads the scheduled revocation ETA from `pendingRevocationEta`.

Revocation is two-step and **not** instant. `initiateRevokeDelegation` only schedules; the contract keeps enforcing the delegation for the whole cooldown, so every "is it active?" read keeps answering yes until the ETA passes. [`getPendingRevocationEtas`](/core/instant-layer/get-pending-revocation-etas) is what makes a revocation in flight visible.

Contract reference: [SYMMIO perps-core v0.8.6 docs](https://github.com/SYMM-IO/perps-core/tree/version_0.8.6/docs/v0.8.6).

Each method has its own page with the full signature, parameters, return shape, examples, and query options.

## Query options

Each read ships a matching `…QueryOptions` factory and a `…QueryKey` builder for TanStack Query. See each read's page for the exact call.

## Raw ABI

The `instantLayerAbi` export is available for consumers that want to call the contract directly with viem. The `InstantLayer` address is resolved per chain from the config (`config.getChainConfig(chainId)`), not exported as a standalone constant.
