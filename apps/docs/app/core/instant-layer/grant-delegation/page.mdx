# grantDelegation

Grant a delegated signer access to one or more selectors until an expiry timestamp.

```ts
import { grantDelegation } from "@symmio/trading-core";

const hash = await grantDelegation(config, {
  account: { addr: account, isPartyB: false },
  delegatedSigner: delegate,
  selectors: ["0x501e891f"],
  expiryTimestamp: 1_766_000_000n,
});
```

## Parameters

<Properties>
  <Property name="account" type="InstantLayerAccount" typeHref="/core/instant-layer/instant-layer-account" required>
    Account that grants the delegation. The connected wallet must own this account.
  </Property>
  <Property name="delegatedSigner" type="Address" required>
    Signer that may call the selected Instant Layer functions.
  </Property>
  <Property name="selectors" type="readonly Hex[]" required>
    Function selectors (`bytes4[]`) to grant. For the instant-trade lifecycle, resolve the chain's set with
    `getInstantTradeRequiredSelectors(config, {chainId})` — the open-leg selector is per-chain (`sendQuote` on a
    perps-core v0.8.6 chain, the legacy `sendQuoteWithAffiliateAndData` on v0.8.5). The static sets
    (`INSTANT_TRADE_REQUIRED_SELECTORS` / `LEGACY_INSTANT_TRADE_REQUIRED_SELECTORS`) are exported for single-chain
    flows.
  </Property>
  <Property name="expiryTimestamp" type="bigint" required>
    Expiry timestamp in seconds.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
  <Property name="simulateBeforeWrite" type="boolean" optional>
    Dry-run via `simulateContract` first (defaults to the config's setting, itself `true` by default). Ignored on the
    relayed path — there is no transaction to dry-run, and the relayer simulates its own bundle.
  </Property>
  <Property name="gasless" type="boolean | GaslessWriteOptions" optional>
    Relay the grant instead of sending a transaction. Omitted, the chain's `gasless.execution.mode` decides. See
    [relayable writes](/core/gasless/relayable-writes).
  </Property>
</Properties>

## Returns

<Returns type="Hash">
  The submitted transaction hash. A relayed grant returns the relayer's broadcast hash, which behaves exactly like a
  wallet-submitted one — so the transport never leaks into the type. Dry-run without sending via
  `simulateGrantDelegation(config, params)`.
</Returns>

<Callout type="info">
  **This grant costs no native gas under [gasless](/core/gasless) execution.** The grant is itself a relayable write, so
  a wallet with an empty balance can still onboard a session key. Pass
  [`GASLESS_SESSION_KEY_SELECTORS`](/core/gasless/relayable-writes) as `selectors` — never
  `GASLESS_RELAYABLE_SELECTORS`, which includes `grantDelegation` itself and would let the key re-delegate.
</Callout>

<Callout type="warning">
  A `isPartyB: true` account cannot be relayed — the signed-operation encoder has no PartyB form. Such a grant takes the
  wallet path, and throws `GASLESS_PARTYB_UNSUPPORTED` if gasless was demanded explicitly with `gasless: true`.
</Callout>
