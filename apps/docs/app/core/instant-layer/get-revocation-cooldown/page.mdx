# getRevocationCooldown

Read the Instant Layer's global delegation revocation cooldown, in seconds.

```ts
import { getRevocationCooldown } from "@symmio/trading-core";

const cooldownSeconds = await getRevocationCooldown(config, {});
```

This is the delay the two-step revocation enforces. [`initiateRevokeDelegation`](/core/instant-layer/initiate-revoke-delegation) stamps `pendingRevocationEta = block.timestamp + revocationCooldown`; [`finalizeRevokeDelegation`](/core/instant-layer/finalize-revoke-delegation) reverts until that ETA passes.

This value is the _size_ of the residual authority window, not a countdown for any particular revocation. To know when a specific one lands, read [`getPendingRevocationEtas`](/core/instant-layer/get-pending-revocation-etas).

Surface it wherever you offer revocation, so a user learns **before** they start that a compromised key keeps signing for the cooldown's duration.
