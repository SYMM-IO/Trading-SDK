# deallocate

Move a subaccount's allocated (tradeable) balance back into its available balance — the reverse of [`allocate`](/core/account-layer/allocate). Routed through the AccountLayer `_call` proxy; the connected wallet must be the subaccount's on-chain `owner`. Requires a fresh Muon uPnL attestation so the contract can verify the subaccount stays solvent, and is subject to the on-chain **deallocate debounce**.

```ts
import { deallocate, getDeallocateUpnlSig } from "@symmio/trading-core";

const upnlSig = await getDeallocateUpnlSig(config, { virtualAccount: "0xsub..." });
const hash = await deallocate(config, {
  account: "0xsub...",
  amount: 1_000000000000000000n, // 18 decimals
  upnlSig,
});
```

## Parameters

<Properties>
  <Property name="account" type="Address" required>
    The subaccount to deallocate from. The signer must equal its on-chain `owner`.
  </Property>
  <Property name="amount" type="bigint" required>
    Amount moved back into available balance, in **18 decimals** (not collateral decimals).
  </Property>
  <Property name="upnlSig" type="SingleUpnlSig" required>
    A fresh Muon uPnL attestation — fetch with `getDeallocateUpnlSig` right before submitting.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
  <Property name="simulateBeforeWrite" type="boolean" optional>
    Dry-run via `simulateContract` first (defaults to the config's setting, itself `true` by default).
  </Property>
</Properties>

## Returns

<Returns type="Hash">The broadcast tx hash. Dry-run without sending via `simulateDeallocate(config, params)`.</Returns>
