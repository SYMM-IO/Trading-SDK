# encodeSubAccountHookMetadata

Encode the `metadata` blob of a new subaccount, so the affiliate's `onAccountCreation` hook can decode it.

```ts
import { encodeSubAccountHookMetadata } from "@symmio/trading-core";

const metadata = encodeSubAccountHookMetadata({ rflCode: username, partyBToBind: solverAddress });
```

`createSubAccounts` stores the blob verbatim and hands it to the affiliate's hook. An affiliate with a hook decides the
encoding, and a blob it cannot decode fails the whole creation with `HookFailed`. Every SYMMIO deployment the SDK ships
uses one tuple, which this helper encodes:

```solidity
abi.encode((string rflCode, uint256 referrerTokenId, address partyBToBind))
```

Pass the result as `SubAccountCreationData.metadata` to [`createSubAccounts`](/core/account-layer/create-sub-accounts),
or as `accountData.metadata` to
[`settleGaslessDepositNewAccount`](/core/gasless/settle-gasless-deposit-new-account).

<Callout type="warning">
  **`rflCode` is global and single-use.** The hook keeps referral codes in one namespace across every wallet, and a code
  that is already registered reverts the creation (`HookFailed(0x7ab9fd97)`). Never pass a fixed literal. Use a handle
  your product owns and knows is free, such as a username, or omit it: an empty code is skipped rather than stored, so
  it stays reusable, even twice in one `createSubAccounts` call.
</Callout>

## Parameters

<Properties>
  <Property name="rflCode" type="string" optional default='""'>
    Referral code to register for the subaccount. See the warning above.
  </Property>
  <Property name="partyBToBind" type="Address" optional>
    PartyB (solver) the hook binds the subaccount to — the chain's solver address. Omit it, or pass the zero address,
    only when the affiliate binds none.
  </Property>
  <Property name="referrerTokenId" type="bigint" optional default="0n">
    Referrer NFT id; `0n` when there is no referrer.
  </Property>
</Properties>

## Returns

<Returns type="Hex">
  The ABI-encoded tuple, or `"0x"` when there is no PartyB to bind. An affiliate that binds a PartyB always has one
  configured, so with nothing to hand the hook, the empty blob is what a hookless affiliate expects.
</Returns>
