# getVirtualAccountsCountOfSubAccount

Read how many Virtual Accounts (VAs) a subaccount holds. Use it to page the VA lists past their default limit of 200; below that, one list call already returns every VA.

```ts
import { getVirtualAccountsCountOfSubAccount } from "@symmio/trading-core";

const count = await getVirtualAccountsCountOfSubAccount(config, { subAccount });
```

## Parameters

<Properties>
  <Property name="subAccount" type="Address" required>
    The subaccount whose VAs to count.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
</Properties>

## Returns

<Returns type="bigint">The number of VAs the subaccount holds.</Returns>
