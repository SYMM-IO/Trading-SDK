# getAccountBalanceOf

Read the account's **available balance** — deposited collateral idle on the account. **For the instant (lowcap) flow this is the trading balance**: deposits credit it, instant opens spend it, and withdrawals draw from it. Read via `balanceOf(account)` on the SYMMIO diamond. See [Balance Model](/core/concepts/balance-model).

Pair with [`getAccountBalanceInfo`](/core/account-layer/get-account-balance-info) for the full picture: `balanceOf` is the free-to-move pot; `balanceInfoOfPartyA` is the classic pool (allocated and locked) — which instant opens do **not** spend.

```ts
import { getAccountBalanceOf } from "@symmio/trading-core";

const balance = await getAccountBalanceOf(config, {
  account: "0xaccount...",
});
```

## Parameters

<Properties>
  <Property name="account" type="Address" required>
    Account address passed to `balanceOf`.
  </Property>
  <Property name="chainId" type="number" optional>
    Optional chain override.
  </Property>
</Properties>

## Returns

<Returns type="bigint">
  The protocol's **18-decimal** internal units (not the collateral token's decimals). Use `formatUnits(value, 18)` /
  `formatEther(value)` or the utils package when displaying decimal values.
</Returns>
