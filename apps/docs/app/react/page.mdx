# React

`@theoldvarorg/react` is the React adapter for the SYMMIO SDK. Hooks, providers, and `react-query`-shaped wrappers on top of `@theoldvarorg/core`.

## Install

```sh
pnpm add @theoldvarorg/react viem wagmi @tanstack/react-query
```

`react`, `react-dom`, `viem`, and `wagmi` are peer dependencies. `@theoldvarorg/core`, `@theoldvarorg/utils`, `decimal.js`, and `zustand` are pulled in transitively.

## Mount the providers

The SDK assumes the host mounts wagmi and `@tanstack/react-query` itself. That keeps the host in control of connectors, RPC URLs, and the shared `QueryClient`.

```tsx
<WagmiProvider config={wagmiConfig}>
  <QueryClientProvider client={queryClient}>
    <SymmioProvider config={symmioConfig}>{children}</SymmioProvider>
  </QueryClientProvider>
</WagmiProvider>
```

See **[Getting Started](/getting-started)** for a complete `Providers` component.

## Convenience re-exports

`@theoldvarorg/react` re-exports the most-used helpers from `@theoldvarorg/utils` so apps don't have to add a second dependency for formatters:

- `formatTokenAmount`, `parseTokenAmount`, `rawToDecimal`, `decimalToRaw` (from `@theoldvarorg/utils/amounts`)
- `shortenAddress` (from `@theoldvarorg/utils/address`)

Apps that want the full utils surface (Decimal helpers, currency formatters, …) should depend on `@theoldvarorg/utils` directly. See **[Utils](/utils)**.

It also re-exports types from `core` (`SubAccountDetail`, `SubAccountIsolationType`, `EditAccountNameParams`, `SymmError`) so `apps/web`-style consumers don't need to depend on `core` directly.
