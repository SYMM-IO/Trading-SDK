# Notional Cap hooks

Available-liquidity gates. Use these to prevent a trade from being submitted when the solver has no room for it.

**Read only.**

## Import

```ts
import { useNotionalCapAll, useNotionalCapBySymbolId, useOpenInterestBySymbolId } from "@symmio/trading-react";
```

## `useNotionalCapBySymbolId`

Cap for a single market.

```ts
const cap = useNotionalCapBySymbolId({ symbolId: 1n });
```

## `useNotionalCapAll`

Every market's cap across all pages. Cheaper than looping the by-id variant.

```ts
const caps = useNotionalCapAll();
```

## `useOpenInterestBySymbolId`

Used vs capped notional per market.

```ts
const oi = useOpenInterestBySymbolId({ symbolId: 1n });
```

## `useNotionalCapPage`

Use this hook for an explicitly paginated table. It accepts `UseNotionalCapPageParameters`: core page options plus optional `config` and `pollingInterval` (same default as `useNotionalCapAll`; `false` disables polling). Its `UseNotionalCapPageReturnType` exposes query data, loading and normalized error state. Totals describe the returned page only. See [core pagination and units](/core/solvers#getnotionalcappage).

```tsx
import { useNotionalCapPage } from "@symmio/trading-react";
const page = useNotionalCapPage({ chainId: 42161, limit: 100, offset: 100 });
```

The console Solvers page includes separate `getNotionalCapAll` and `getNotionalCapPage` cards. The page card exposes limit/offset controls, per-page rows and page-only totals; the all-markets card shows aggregate totals.
