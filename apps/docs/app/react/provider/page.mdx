# SymmioProvider

The single context every other SDK hook consumes.

## Setup

```tsx
import { SymmioProvider, SymmioSupportedChainId } from "@symm-frontier/react";

<SymmioProvider
  config={{
    chainId: SymmioSupportedChainId.HYPER_EVM,
    affiliateAddress: "0xYourAffiliateAddress",
  }}
>
  {children}
</SymmioProvider>;
```

**Must be mounted inside a `WagmiProvider` and `QueryClientProvider`.** The SDK reads both from context but does not mount them itself. See **[Getting Started](/getting-started)** for the full tree.

## `SymmioClientConfigInput`

```ts
interface SymmioClientConfigInput {
  chainId: SymmioSupportedChainId;
  affiliateAddress: Address;

  // optional per-chain overrides
  addresses?: Partial<SymmioContractAddresses>;
  subgraphs?: Partial<SymmioSubgraphUrls>;
  solver?: Partial<SymmioSolverConfig>;
}
```

The provider merges your input with the built-in defaults for the chain, creates a `SymmioClient`, and exposes it via `useSymmioClient()`.

## `useSymmioClient`

Access the SDK client from context. Returns `undefined` if wagmi has no transport for the configured chain.

```tsx
import { useSymmioClient } from "@symm-frontier/react";

function Banner() {
  const client = useSymmioClient();
  if (!client) return <p>Chain not configured</p>;

  return (
    <p>
      Trading against {client.config.solver.name} on chain {client.config.chainId}.
    </p>
  );
}
```

The client provides bound methods (`getUserSubAccounts`, `getMarkets`, `editAccountName`) and the resolved config at `client.config`.

## Client shape

```ts
interface SymmioClient {
  config: SymmioChainConfig; // resolved addresses, subgraphs, solver
  publicClient: PublicClient; // viem public client
  walletClient?: WalletClient; // viem wallet client (if connected)

  // Bound methods
  getUserSubAccounts(params: { user: Address }): Promise<SubAccountDetail[]>;
  getMarkets(): Promise<Market[]>;
  editAccountName(params: { account: Address; name: string }): Promise<Hash>;
}
```

`addresses.accountLayerAddress` is the address every account-layer hook uses by default. Each hook also accepts a per-call `accountLayerAddress` override.

## Internal client hooks

These are exported but mostly internal — domain hooks call them on your behalf. Useful if you want to compose your own queries on top of the SDK.

### `useSymmioPublicClient`

Returns a viem `PublicClient` for the configured chain, sourced from the host's wagmi config. `undefined` when wagmi has no transport bound for the chain.

### `useSymmioWalletClient`

Returns wagmi's `useWalletClient` result scoped to the configured chain — full `{ data, status, error }` shape. `data` is `undefined` until the user connects a wallet **and** is switched to the SDK's chain.
