# Wallet hooks

Thin wrappers over wagmi's wallet hooks, with the SDK's chain-awareness and error normalization layered on top.

The page is split into two groups:

- **[Reads](#reads)** — `useWalletAccount`.
- **[Writes](#writes)** — `useConnectWallet`, `useDisconnectWallet`, `useSwitchToSymmioChain`. These are "actions" rather than TanStack mutations, but they still trigger side effects (wallet popups, chain switches) so the split applies.

## Reads

### `useWalletAccount`

Read the connected wallet's state plus an `isOnExpectedChain` flag.

```tsx
import { useSymmioChainId, useWalletAccount } from "@symmio/trading-react";

const { address, chainId, isConnected, isReconnecting, isOnExpectedChain } = useWalletAccount();
const targetChainId = useSymmioChainId();

if (!isConnected) return <ConnectButton />;
if (!isOnExpectedChain || chainId !== targetChainId) return <SwitchNetworkPrompt />;
return <Dashboard address={address} />;
```

`isOnExpectedChain` is `true` when the wallet is connected to **any** chain the SDK supports. It does not check the chain your app targets: with `SymmioProvider`'s [`chainId`](/react/provider#chainid) pinned to Arbitrum, a wallet on Base still reads `true`. To decide on a switch prompt, also compare the wallet's `chainId` with [`useSymmioChainId()`](/react/provider#usesymmiochainid), as above.

`chainId` here is the wallet's actual chain. Use it, not `useSymmioChainId()`, whenever you need to know where the connected wallet really is.

## Writes

### `useConnectWallet`

```tsx
import { useConnectWallet } from "@symmio/trading-react";

const { connectors, connect, status, error } = useConnectWallet();

return connectors.map((connector) => (
  <button key={connector.uid} onClick={() => connect(connector)} disabled={status === "pending"}>
    Connect {connector.name}
  </button>
));
```

`connectors` is whatever the host's wagmi config registered (`injected()`, `walletConnect()`, `mock()`, …). The SDK does not pick connectors for you. Errors thrown from `connect()` are already normalized to `SymmioRequestError`.

### `useDisconnectWallet`

```tsx
const { disconnect } = useDisconnectWallet();
<button onClick={disconnect}>Disconnect</button>;
```

### `useSwitchToSymmioChain`

Ask the wallet to switch to the chain configured in `SymmioProvider`. Convenience wrapper over wagmi's `useSwitchChain` that pulls the target chain id from the SDK config.

```tsx
const { chainId, isOnExpectedChain } = useWalletAccount();
const targetChainId = useSymmioChainId();
const { switchChain, status } = useSwitchToSymmioChain();

if (!isOnExpectedChain || chainId !== targetChainId) {
  return (
    <button onClick={switchChain} disabled={status === "pending"}>
      Switch to {/* chain name from config */} Arbitrum
    </button>
  );
}
```

Errors are normalized — `error?.kind === "user-rejected"` when the user dismisses the prompt.
